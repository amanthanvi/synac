# Contributing

SynAc is released at `v0.1.1` and under active development for `v0.1.x`.

## Workflow

- Keep diffs small/medium.
- Use Conventional Commits (`feat:`, `fix:`, `docs:`, `chore:`, ...).
- Prefer updating `SPEC.md` when implementation diverges from the spec.

This project follows `CODE_OF_CONDUCT.md`.
