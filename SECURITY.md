# Security Policy

## Reporting a Vulnerability

If you believe you have found a security vulnerability in SynAc, please report it
privately.

- Email: `amanthanvi2002@gmail.com`
- Please include: affected component(s), reproduction steps, impact, and any
  suggested remediation.

Do **not** open a public GitHub issue for security-related reports.

## Response Targets

- Acknowledge within **72 hours**
- Provide a status update within **7 days**

If you need an encrypted channel, request a PGP key in your initial email.
