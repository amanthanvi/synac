# Support

SynAc is a small project. Support is best-effort.

## Where to ask questions

- **GitHub Discussions** (preferred): project Q&A, “how do I…?”, design feedback
- **GitHub Issues**: bugs, content corrections, and feature requests

## Security issues

Do **not** open public issues for security reports. Follow `SECURITY.md`.

## What to include

For bugs:

- URL (if applicable)
- What happened / what you expected
- Steps to reproduce
- Screenshots (if UI-related)
- Environment (OS + browser)

For content corrections:

- Entry URL
- What’s wrong / what you believe is correct
- Supporting citation(s) / source link(s)
